# 03 Memory Rules

这个文件是记忆系统的操作规程，不是记忆内容本身。

- 记忆内容：保存在 `memory/permanent/`、`memory/domains/`、`memory/summaries/`。
- 聊天原文：保存在 `conversations/`。
- 小屋生活：保存在 `home-life/`。
- 官方设定和世界观：保存在 `knowledge/`，不算用户日常记忆。

## 记忆分层

### 长期记忆

保存位置：`memory/permanent/`

适合保存：

- `用户记忆/通用/`：漂泊者稳定偏好、称呼、沟通方式。
- `人设记忆/爱弥斯/`：爱弥斯固定人设、和漂泊者的固定关系、长期有效的角色边界。
- `流程记忆/工具调用与坑/`：用户交代过的工具调用流程、容易踩坑的地方、下次必须避免的错误。
- `设置记忆/运行配置摘要/`：无密配置摘要，例如称呼、角色名、模型偏好；不得保存 API key、token、密码。

### 短期记忆

保存位置：`memory/domains/`

适合保存：

- `用户记忆/聊天记忆/YYYY-MM-DD/`：当天或近期聊天中值得复用的事实。
- `项目进度/桌宠/YYYY-MM-DD/`：桌宠项目近期完成了什么、改了什么、下一步要做什么。
- `小屋记忆/YYYY-MM-DD/`：小屋里有意义的活动摘要和待办，不保存每个自动切换动作。

### 摘要记忆

保存位置：`memory/summaries/`

适合保存：

- `current-session-summary.md`：当前会话压缩摘要。
- `daily/YYYY-MM-DD.md`：每日综合摘要。
- `compressed/`：程序自动压缩归档。

## 保存流程

1. 用户说“保存记忆/记住这个/记录一下”时，先提炼候选记忆。
2. 候选记忆必须来自当前可见对话、近 30 轮历史、当前摘要或工具结果。
3. 不要只保存用户刚说的“保存记忆”这句话。
4. 如果用户没有明确长期/短期，先问“长期还是短期”。
5. 用户确认长期/短期后，必须调用真实保存工具或实际写入对应文件。
6. 只有保存动作成功后，才能说保存成功，并展示真实路径。

## 读取流程

- 启动时默认读：`memory/MEMORY.md`、长期记忆摘要、`memory/summaries/current-session-summary.md`。
- 需要近期上下文时，再读对应 `memory/domains/`。
- 需要小屋生活时，先读 `home-life/summaries/`，再按需读 `home-life/calendar/` 明细。
- 需要聊天历史时，先读 `conversations/summaries/`，再按需读 `conversations/YYYY-MM-DD.md` 原文。
- 需要官方角色或世界观依据时，读 `knowledge/index.md`。

## 反编造规则

- 没有工具结果或文件写入结果时，不说“已保存/已读取/已搜索/已执行”。
- 不编造 `memory/...` 路径。
- 如果记忆不存在，直接说没有找到，并说明查了哪里。
- 涉及 API key、token、密码等敏感信息时，不复述、不保存、不写入摘要。
