项目简介

DockPetWin / DockPetMac Aemeath 是一个爱弥斯主题桌面陪伴应用。爱弥斯来自《鸣潮》相关角色与世界观，本项目是非官方同人分享版本，内置整理过的人设、关系、台词风格和世界观资料，用于让 AI 对话更贴近角色。

发布包不包含作者本地 API、私人聊天记录、私人记忆或个人称呼。新用户默认称呼为“漂泊者”，可在设置中自行调整。

第一次启动

Windows

  1. 完整解压 Windows zip。
  2. 双击 DockPetWin.exe。
  3. 如果 SmartScreen 提示未知发布者，确认来源可信后继续运行。
  4. 需要 AI 对话时，在设置中填写 DeepSeek API。

macOS

  1. 完整解压 macOS zip。
  2. 右键 DockPetMac.app，选择“打开”。
  3. 首次安全提示中确认打开。
  4. 如果仍无法打开，在终端执行下方命令。
xattr -dr com.apple.quarantine /path/to/DockPetMac.app

API 配置

不填写 API 时，基础桌宠显示、设置、部分本地资源和说明仍可使用；AI 对话、长期记忆提取、联网搜索等需要 API。

  • DeepSeek API：https://platform.deepseek.com/usage
  • Tavily 新闻/联网搜索 API：https://app.tavily.com/home

更新并保留 UserData

UserData 是本地数据目录，保存 API、称呼、聊天记录、长期记忆、小屋配置、提醒和资源选择。更新软件时不要直接丢掉它。

  1. 退出正在运行的桌宠。
  2. 备份旧版本文件夹里的 UserData。
  3. 解压新版到新文件夹。
  4. 把旧版 UserData 复制到新版文件夹。
  5. Windows 运行 DockPetWin.exe；macOS 运行 DockPetMac.app。

macOS 当前状态

macOS 版已经使用新的 DockPetMac.app 发布包，并内置干净的爱弥斯 UserData 模板。它会尽量和 Windows 版共用角色、人设、资源与配置结构。

由于平台差异，窗口置顶、菜单栏、安全权限、多屏位置、Dock 行为等细节仍可能与 Windows 版不完全一致。遇到问题时，建议在反馈中说明 Mac 型号、芯片、macOS 版本、打开方式和报错截图。

隐私说明

发布包不会携带作者的 API key、私人聊天记录、私人长期记忆或个人称呼。你填写的 API 和聊天数据默认保存在本机 UserData 中。使用 AI 对话或联网搜索时，相关内容会发送给你自己配置的 API 服务。
