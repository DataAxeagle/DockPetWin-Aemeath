# 功能对齐清单

## 必须保留

- 爱弥斯默认角色和像素风人物素材。
- 默认称呼用户为“漂泊者”。
- 新用户 API 配置引导，且台词符合爱弥斯人设。
- DeepSeek API 配置。
- Tavily 新闻搜索 API 配置。
- AI 聊天、长期记忆、清除当前上下文。
- 小屋、家具、人物动作、行事历动作池。
- 右键/菜单栏功能：聊天、设置、小屋、重启、退出。
- 用户数据和应用更新分离，升级时保留设置、聊天、记忆、偏好。
- 开源版本不包含本地 API key、私人聊天记录和用户专属称呼。

## macOS 等价实现

Windows 桌宠贴近任务栏移动，在 macOS 上应改成“屏幕边缘 / Dock 附近”的等价体验。

| Windows 版能力 | macOS 版等价 |
| --- | --- |
| WPF 透明无边框窗口 | Avalonia 透明无边框窗口 |
| Windows 托盘图标 | macOS 菜单栏图标 |
| 任务栏区域几何 | 屏幕工作区 + Dock/Menu Bar 规避 |
| 右键菜单 | 桌宠右键菜单 + 菜单栏菜单 |
| exe 启动器 | `.app` bundle / `.dmg` |
| UserData 在运行目录 | 用户数据目录，例如 `~/Library/Application Support/DockPetWin-Aemeath/` |

## 首版可接受差异

- 可以先只支持 Apple Silicon Mac。
- 可以先不支持开机自启。
- 可以先不做自动更新。
- 小屋动画可以先保持 Windows 资源帧和点位逻辑，再做 macOS 坐标细调。

## 不可接受差异

- 不能打开后变成默认宠物。
- 不能要求用户手动复制一堆素材才能启动。
- 不能把 API key 打进发布包。
- 不能丢失爱弥斯角色、人设、默认引导和基础聊天能力。
